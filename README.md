Backend-for myfinance AI

## clone repo

```bash
git clone <repo-url>
cd my-finance-AI-backend
```

## create venv
```bash
python -m venv venv
venv\Scripts\activate  
```

## install requirement
```bash
pip install -r requirements.txt
```

## run server
```bash
uvicorn app.main:app --reload
```

## documentation
```bash
http://127.0.0.1:8000/docs
```
